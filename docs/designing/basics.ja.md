# 基本情報

**基本情報** のカテゴリでは、プロジェクト全体に関わる設定を行います。

![基本情報のページ](../images/ja/designing/basics.png)

## 項目の一覧

| 項目 | 内容 |
|---|---|
| **プロジェクト名** | プロジェクトの題名です。ダイアログのタイトルなどに表示されます。プロジェクトのファイル名（プロジェクトID）とは別のものです。 |
| **説明** | プロジェクトの説明です。自由に書けます。 |
| **カット番号接頭辞 [PREFIX]** | カット番号の前に付ける文字列です（下を参照）。 |
| **プロジェクトのルートフォルダ [ROOT]** | カットのファイルを置くフォルダです。 |
| **進捗情報用フォルダ** | 工程グループの所属、工程ごとのカットの一覧、カット情報を保存するフォルダです（プロジェクト情報フォルダ）。 |
| **履歴のルートフォルダ** | カットごとのログを保存するフォルダです（ログフォルダ）。 |
| **Google Apps スクリプトのURL** | Google スプレッドシート連携と Google Chat 通知で使う、Google Apps Script の URL です（下を参照）。 |
| **Google Chat 投稿先** | Google Chat 通知の投稿先の名前です（下を参照）。 |
| **カットサムネイルのパス** | カットの一覧に表示するサムネイル画像のパスです（下を参照）。 |
| **100カットごとにまとめる [SEQUENCE]** | カットを100カットずつのまとまりに分けて管理するかどうかです（下を参照）。 |
| **話数あり** | TV シリーズなど、複数の話数で構成される作品のときにオンにします（下を参照）。 |

## カット番号の接頭辞 [PREFIX]

カット番号の前に付ける文字列です。
サンプルプロジェクトでは `c` なので、カット `0001` のファイルやフォルダの名前は `c0001` で始まります。

パスの中では `[PREFIX]` と書くと、この文字列に置き換えられます。
カット情報のファイル（`c0001.ini`）やログのファイル（`c0001.md`）の名前にも使われます。

接頭辞を使わない場合は、空のままにします。

## ルート・進捗情報・履歴のフォルダ

3つのフォルダの役割は、[進捗はファイルで管理される](../concepts/progress-files.ja.md) で説明しています。
フォルダの欄の右のボタンを押すと、フォルダを選べます。

**相対パス**で書いた場合は、Stuff フォルダを起点としたパスとして扱われます。
たとえば `sample_data` と書くと、`[Stuffフォルダ]/sample_data` になります。
Stuff フォルダを共有する場合は相対パスを推奨します。絶対パスの欄にはこの端末で使う場所が表示されます。欄にポインターを置くと保存パスを確認できます。対応する設定がない場合は、その旨が表示されます。入力には端末のパスと保存パスのどちらも使えます。他の項目だけを編集したときは元のパスが保持されます。新しく入力した絶対パスに対応する設定がない場合は、確認後にそのまま保存できます。[共有フォルダでの運用](../administration/shared-operation.ja.md)も参照してください。

ルートフォルダは、パスの中で `[ROOT]` と書くと、このフォルダに置き換えられます。
通常は、[パスマクロ](path-macros.ja.md) で決めるカットフォルダの場所を、`[ROOT]/...` の形で書きます。

## 話数 [EPISODE]

TV シリーズのように、複数の話数で構成される作品では、**話数あり** をオンにして、**話数の名前** を入れます。
話数の名前は、カンマ（`,`）かセミコロン（`;`）で区切って入れます（例：`01, 02, 03`）。

話数ありにすると、次のようになります。

- メイン画面に、話数を切り替えるコンボボックスが表示されます（[メイン画面](../using/main-window.ja.md) を参照）。
- パスの中の `[EPISODE]` が、メイン画面で選んでいる話数の名前に置き換えられます。カットフォルダのパスに `[EPISODE]` を入れておくと、話数ごとにフォルダを分けられます。
- 進捗情報用フォルダと履歴のルートフォルダの中に、話数ごとのフォルダが作られ、その中に記録が保存されます。

## 100カットごとにまとめる [SEQUENCE]

オンにすると、カットを100カットずつのまとまり（**シークエンス**）に分けて管理します。

- パスの中の `[SEQUENCE]` は、カット番号の先頭の数字から、下2けたを除いたものになります（例：`0123` → `01`、`0045` → `00`）。
- カット情報とログは、シークエンスごとのフォルダ（`00`、`01`…）に分けて保存されます。
- カット名は、3けた以上の数字で始まる必要があります（`0123`、`0123b` など）。

オフにすると、次のようになります。

- `[SEQUENCE]` は使えません（空の文字列に置き換えられます。前後の `/` は1つにまとめられます）。
- カット情報とログは、シークエンスのフォルダを作らずに保存されます。
- カット名は自由に付けられます。

> **注意**：この設定は、制作の途中で変えないでください。
> PPM は、すでにあるカット情報とログのフォルダを並べ替えません。
> 変えると、それまでのカット情報（テイクの記録を含む）とログが見つからなくなります。
> 変えて保存しようとすると、確認のメッセージが表示されます（[運用中に設計を変えるときの注意](changing-in-production.ja.md) を参照）。

## カットサムネイルのパス

カットの一覧の「サムネイル」の列に表示する画像のパスです。
`[ROOT]`、`[PREFIX]`、`[SEQUENCE]`、`[CUTNUMBER]`、パスマクロなどを使って書きます（例：`[ROOT]/thumbnails/[PREFIX][CUTNUMBER].jpg`）。

空のままにすると、カットの一覧にサムネイルの列は表示されません。

## Google Apps Script の URL と Google Chat の投稿先

Google スプレッドシートに進捗を書き込んだり、Google Chat に通知を送ったりするときに使います。
使わない場合は、空のままにします。

- **Google Apps スクリプトのURL**：知っている人なら誰でも使えてしまう URL なので、画面には表示されず、難読化して保存されます。変えるときは、欄を全選択（Ctrl+A）してから、新しい URL を入れます。
- **Google Chat 投稿先**：「Google Chat に通知を送る」ステップで選べる投稿先の名前を、カンマかセミコロンで区切って入れます。**スクリプトから取得** で、スクリプトに登録されている名前を読み込めます。**テストメッセージを送信** で、試しに投稿できます。

設定の手順は、[Google スプレッドシート連携](../integrations/google-spreadsheet.ja.md) と [Google Chat 通知](../integrations/google-chat.ja.md) で説明します。
