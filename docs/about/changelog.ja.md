# 更新履歴

PPM の各バージョンで変わったことを、新しいものから順に書きます。
使っている PPM のバージョンは、macOS の **PPM** メニューまたは Windows の歯車メニューの **PPM について** で確かめられます。

## 1.0（YYYY-MM-DD）

最初の公開版です。

- 工程・工程グループ・アクションを、プロジェクト設定の画面で設計できます（一覧表示とフローチャート表示）。
- キューファイルの有無から、各カットがいる工程を一覧にします。
- アクションで、リネーム、コピー、キューファイルの作成、カット情報の登録などのステップを、確認画面を挟んでまとめて実行し、取り消せます。
- リテイクと工程内リテイク、傍流、条件分岐に対応しています。
- Google スプレッドシートへの書き込みと、Google Chat への通知ができます。
- リネームスクリプト（JavaScript）で、ファイル名の付け替えの決まりを足せます。
- 画面の言語は、英語と日本語です。翻訳ファイルで、ほかの言語を追加できます。
