# 不具合報告・要望

## 報告先（GitHub Issues）

不具合の報告や機能の要望は、GitHub の [Issues](https://github.com/opentoonz/ppm/issues) で受け付けています。

報告する前に、次のことを確かめてください。

- [トラブルシューティング / FAQ](../troubleshooting.ja.md) に、同じ症状と対処が書かれていないか
- 同じ内容の Issue が、すでに出されていないか（出されていれば、その Issue に情報を書き足してください）

1つの Issue には、1つの不具合か、1つの要望だけを書いてください。
日本語でも英語でもかまいません。

## 添えてほしい情報

不具合を報告するときは、次の情報があると、原因を調べやすくなります。

| 情報 | 調べ方 |
|---|---|
| PPM のバージョン | macOS の **PPM** メニューまたは Windows の歯車メニューから **PPM について** を開くと、バージョンとビルドされた日が表示されます。 |
| Windows のバージョン | Windows 10 か 11 か。 |
| PPM の画面の言語 | [環境設定](../using/preferences.ja.md) の **言語** です。 |
| 何をしたか | 押したボタンや、選んだ工程・アクションを、順に書きます。 |
| 何が起きたか、何が起きると思っていたか | 両方を書きます。 |
| 表示されたメッセージ | 警告の文をそのまま書きます。アクションが失敗したときは、**Show Details...** の内容も添えます。 |
| カットのログ | 関係するカットのログの行です（[バックアップと復旧](../administration/backup.ja.md) の「ログから経緯をたどる」を参照）。 |
| 画面のキャプチャ | 画面の様子がわかると、伝わりやすくなります。 |
| 毎回起きるか | 同じ操作で毎回起きるか、ときどき起きるか。 |

できれば、配布物に含まれるサンプルのプロジェクト（[チュートリアル：カットを1つ最後まで進める](../getting-started/tutorial.ja.md) で使うもの）で、同じことが起きるかを確かめてください。
サンプルで起きる不具合は、開発者の手元でも同じ手順で確かめられます。

## 報告に含めないでほしい情報

Issues は、誰でも読めます。
次のものは、Issue に書いたり添付したりしないでください。必要なら、名前を伏せたり、架空の名前に置き換えたりしてください。

- 作品名や、公開前の作品の画像
- 共有フォルダのサーバー名やパス
- スタッフの名前（ログのユーザー名など）
- Google Apps Script の URL
- プロジェクトのファイル（`.ppmprj`）そのもの。上のような情報が含まれています。

## セキュリティに関わる不具合

難読化したパスや Google Apps Script の URL が漏れてしまう、といったセキュリティに関わる不具合は、公開の Issues には書かず、次のメールアドレスに連絡してください。

- shun.iwasawa@ponoc.jp

連絡を受け取ることは、その問題の解決に取り組むことを約束するものではありません。
オープンソースのソフトウェアの開発と利用は、それぞれの責任において行うことが基本です。

## 要望

機能の要望も、Issues で受け付けています。
次のことを書いてもらえると、検討しやすくなります。

- 制作の中で、どんな場面で困っているか
- 今はどうやって対応しているか
- どうなるとうれしいか
