# Changelog

This page lists what changed in each version of PPM, newest first.
You can check the version of your PPM in **About PPM** in the **PPM** menu on macOS or the gear menu on Windows.

## 1.0 (YYYY-MM-DD)

The first public release.

- Workflows, workflow groups, and actions can be designed in the project settings dialog (list view and flowchart view).
- PPM lists which workflow each scene is in, from whether the cue files exist.
- Actions run steps such as renaming, copying, creating cue files, and setting scene info tags together after a confirmation dialog, and can be undone.
- Retakes, rewinds, branch flows, and conditional branches are supported.
- PPM can write to Google Spreadsheets and send notifications to Google Chat.
- Rename scripts (JavaScript) can add rules for renaming files.
- The UI is available in English and Japanese. Other languages can be added with translation files.
