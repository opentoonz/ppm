# カットに対する操作

カットの一覧の各行から行える操作を説明します。

## ファイルを開く

**開く** の列には、次のボタンが並んでいます。

| ボタン | 働き |
|---|---|
| **開く** | カットのファイルを、作業用のアプリで開きます。 |
| **タイムシートを開く**（XDTS のアイコン） | カットのタイムシート（`.xdts`）を開きます。タイムシートが見つからないときは押せません。 |
| **カットフォルダを開く**（フォルダのアイコン） | キューファイルがあるフォルダを、Windows ではエクスプローラー、macOS では Finder で開きます。 |
| **ログを見る**（ログのアイコン） | カットのログを、別のウィンドウで表示します。ログがまだないときは押せません。 |

### 開く ボタン

**開く** ボタンは、キューファイルの種類によって働きが変わります。

- **`.clip`、`.tvpp`、`.tnz` のファイル**：[環境設定](preferences.ja.md) で設定したアプリで開きます。パスが空欄のときは、その拡張子に OS で関連付けられたアプリで開きます。
- **それ以外のファイル**（目印のテキストファイルなど）：カットフォルダを開きます。
  プロジェクト設定で、工程グループに「開くボタンで開くサブフォルダ」が決められている場合は、そのサブフォルダの中の作業ファイルを開きます。
- **兼用カットで、キューファイルが複数ある場合**：ボタンを押すとメニューが表示され、開くファイルを選べます。

ファイルを開いた行は、黄色になります。アプリを起動できなかったときは、メッセージが表示され、行の色は変わりません。

タイムシートが複数見つかった場合も、メニューから開くファイルを選べます。
タイムシートを開くアプリは、[環境設定](preferences.ja.md) の「XDTS用アプリケーションのパス」で決めます。

## アクションを実行する

**アクション** の列のボタンを押すと、アクションを実行します。

1. 確認画面が表示されます。
2. 内容を確かめて **OK** を押すと、ステップが上から順に実行されます。
3. 「アクションが完了しました。」と表示されたら、完了です。

![アクションの確認画面](../images/ja/getting-started/tutorial-action-confirmation.png)

確認画面の上部には、カット名、工程、アクション名が表示されます。
その下に、実行されるステップが、実際のファイル名つきで並びます。
次のことを確かめてから、**OK** を押してください。

- リネーム先やコピー先のファイル名が、意図したものになっているか
- 警告のアイコンが付いているステップがないか（ファイルが見つからない、など）

ステップによっては、確認画面の中で選択肢を選んだり、入力したりするものがあります。

アクションを実行すると、その行は灰色になり、アクションのボタンの代わりに **取り消す** ボタンが表示されます。
カットが次の工程に移ったことは、**リスト更新** を押すと一覧に反映されます。

アクションが途中で失敗したときの対処は、[カットが工程を流れる仕組み](../concepts/scene-flow.ja.md) を参照してください。

## まとめて実行する

アクションが1つだけの工程の行には、左端にチェックボックスが表示されます。
複数の行のチェックボックスをオンにしてから、そのうちのどれかの行のアクションのボタンを押すと、オンにしたすべての行のアクションを、まとめて実行できます。
たとえば、演出チェックのカットを何カットもまとめて承認するときに使います。

![まとめて実行するためにチェックボックスをオンにした行](../images/ja/using/multi-select.png)

- チェックボックスをオンにした行は、青くなります。
- 確認画面には、オンにしたすべてのカットのステップが並びます。
- 工程が違う行も、まとめて実行できます。それぞれの行で、その工程のアクションが実行されます。
- 一部のカットで失敗した場合は、「アクションのいずれかが失敗しました。」と表示されます。成功したカットの行は灰色になり、失敗したカットの行はそのまま残ります。

チェックボックスを1つだけオンにしてアクションのボタンを押した場合は、ふだんどおり、その行のアクションだけを実行します。

## 工程のロック

各工程の右端にある鍵のアイコンで、その工程をロックできます。一覧表示でもフローチャート表示でも使えます。
ロックした工程の行では、アクションのボタンと、まとめて実行のチェックボックスが押せなくなります。

はじめは、すべての工程がロックされています。
自分が担当する工程だけロックを外しておくと、担当外の工程のアクションを間違えて押すことを防げます。
ロックの状態は、プロジェクトごとに記録されます。一覧表示とフローチャート表示で、同じ状態が使われます。

## 取り消す

アクションを実行して灰色になった行の **取り消す** ボタンを押すと、実行したステップを逆の順に元に戻します。

1. 取り消しの確認画面が表示されます（上部に「[アクションの取り消し]」と表示されます）。
2. **OK** を押すと、ステップが逆の順に元に戻され、行は元の色に戻ります。

取り消しには、次の決まりがあります。

- **取り消す** ボタンは、**リスト更新** を押すと消えます。取り消したいときは、リスト更新を押す前に押してください。
- 取り消しを行うと、ログに「[取り消し]」として記録されます。
- ファイルの消去など、取り消せないステップもあります。そのようなステップは、確認画面に「このステップは取り消せません。」と表示されます。
- Google スプレッドシートへの書き込みがあるアクションでは、書き込みが終わるまで **お待ちください...** と表示され、取り消せません。書き込みに失敗した場合は、**取り消す (*)** と表示されます。

リスト更新の後でアクションを戻したくなったときは、ファイルを手で直します（[ファイルを直接扱う](../concepts/working-with-files.ja.md) を参照）。

## 工程内リテイク

工程内リテイクを使うように設定された工程グループでは、形式が「デジタル」の行の **アクション** の列に、**工程内リテイク** のボタン（巻き戻し矢印のアイコン）が表示されます。
カットを、同じ工程グループの前の工程に戻すときに使います。
仕組みは [カットが工程を流れる仕組み](../concepts/scene-flow.ja.md) で説明しています。

1. **工程内リテイク** のボタンを押します。
2. 「どの工程の前に戻しますか？」と表示されるので、戻し先の工程を選んで **選択する** を押します。
   選べるのは、今の工程と、そこから同じ工程グループの中でさかのぼれる工程です。
3. 確認画面で内容を確かめて、**OK** を押します。

![工程内リテイクの戻し先を選ぶ画面](../images/ja/using/rewind-destination.png)

工程内リテイクを実行すると、行は灰色になり、**取り消す** ボタンが表示されます。
ログには「工程内リテイク：〇〇に戻す」と記録されます。
