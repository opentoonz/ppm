# 環境設定

**環境設定**は、PC のユーザーごとの設定です。
Windows では歯車ボタンから **環境設定** を選びます。macOS ではメニューバーの **PPM** から環境設定を開くか、**Command+,** を押します。

はじめて PPM を使うときの設定の手順は、[初回設定](../getting-started/initial-setup.ja.md) で説明しています。
このページでは、各項目の働きと、設定が保存される場所をまとめます。

![環境設定ダイアログ](../images/ja/getting-started/preferences.png)

## 設定項目

| 項目 | 内容 |
|---|---|
| **言語** | PPM の画面に表示する言語です。Stuff フォルダの `loc` フォルダにある翻訳ファイルの言語から選びます。「English」は翻訳を使いません。変更は、次に起動したときに反映されます。 |
| **TVPaint実行ファイルのパス** | `.tvpp` のファイルを開くアプリです。 |
| **Clip Studio実行ファイルのパス** | `.clip` のファイルを開くアプリです。 |
| **XDTS用アプリケーションのパス** | タイムシート（`.xdts`）を開くアプリです（XDTS Viewer、東映アニメーションデジタルタイムシートなど）。 |
| **OpenToonz実行ファイルのパス** | `.tnz` のファイルを開くアプリです。 |
| **OpenToonz起動時の引数** | OpenToonz で `.tnz` を開くときに付け加える起動オプションです。ファイルのパスの前に渡されます。空白で区切って複数書けます。空白を含む値は `"` で囲みます。 |
| **ユーザー名 [USER_NAME]** | プロジェクトの設定の中の `[USER_NAME]` に入る名前です。空欄のときは、ログインしているユーザーの名前を使います。 |

macOS では **...** ボタンでアプリ（`.app`）を選ぶか、実行ファイルのパスを入力します。TVPaint と CLIP STUDIO PAINT の作画ファイルは、macOS を通じて指定したアプリで開きます。XDTS 用アプリを指定した場合は、タイムシートのパスを起動時の引数として渡します。OpenToonz の `.app` を指定した場合は、新しいインスタンスを起動し、起動オプションに続けてシーンのパスを渡します。

アプリのパスを空欄にした項目は、その拡張子に OS で関連付けられたアプリで開きます。
このとき、OpenToonz起動時の引数は使われません。

設定したアプリのパスにファイルが見つからないときや、選んだ言語の翻訳ファイルが見つからないときは、PPM の起動時に警告が表示されます。

## 共有フォルダのパス対応表

環境設定の「共有フォルダのパス対応表...」を開きます。「Stuff フォルダの OS 別の既定値を使う」を外すと、個人用の表を編集できます。共有場所ごとに行を追加し、左にプロジェクトに保存する絶対パスの先頭部分、右にこの端末での場所を入力します。「OK」で表全体を保存します。個人用の表を空にすると変換は行われません。再び既定値にチェックを入れると、その後のスタジオ側の変更も反映されます。対応表を適用するには PPM を再起動します。

管理者は Stuff フォルダに `defaultusersettings_windows.ini` と `defaultusersettings_macos.ini` を置けます。Mac 用の記入例です。

```ini
[PathMappings]
size=1
1\stored=//fileserver/anime
1\local=/Volumes/anime
```

値の区切りにはスラッシュを使います。サーバー名と共有名は平文で保存されます。照合はフォルダ名の境界で行い、大文字小文字とスラッシュの向きは区別しません。開くときは、一致する保存パスのうち最も長いものを使います。欄を編集したときに保存先の候補が複数あれば、使用するパスを選びます。

## 設定の保存

環境設定のメイン画面の各項目は、入力し終えた時点（欄から別の場所に移ったとき）で保存されます。
**OK** ボタンは、画面を閉じるだけです。

Windows では、環境設定は次のファイルに保存されます。

```
%LOCALAPPDATA%\PPM\usersettings.ini
```

（ふつうは `C:\Users\<ユーザー名>\AppData\Local\PPM\usersettings.ini` です。）

macOS では `~/Library/Application Support/PPM/usersettings.ini` に保存されます。`~` はユーザーのホームフォルダです。アプリ本体や Stuff フォルダとは別の場所に保存します。

アプリや表示言語の設定を一度も変えていない場合は、Stuff フォルダの `defaultusersettings.ini` の内容が初期値として使われます。
詳しくは [Stuff フォルダ](../administration/stuff-folder.ja.md) を参照してください。

## 自動で記録される状態

環境設定の画面にある項目のほかに、次の状態も同じファイルに記録され、次に起動したときに引き継がれます。

- 最後に開いていたプロジェクト
- プロジェクトごとの、工程のチェックの状態、一覧表示で開いている工程グループ、工程のロックの状態、選んでいる話数
- 一覧表示／フローチャート表示のどちらを使っているか
- ウィンドウの位置と大きさ、左右の境目の位置
- カットの一覧の列の表示・非表示と、サムネイルの大きさ
