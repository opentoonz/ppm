# メイン画面

PPM を起動すると表示されるメイン画面の各部分と、その使い方を説明します。

## 画面の構成

メイン画面は、左右2つの部分に分かれています。

![メイン画面の全体](../images/ja/home/main-window.png)
![メイン画面の構成](../images/ja/using/main-window-areas.png)

1. **上部のボタン**（左上）：プロジェクトの切り替え、設定、リスト更新、カット登録、リテイク、カット検索のボタンが並びます。
2. **工程の選択**（左）：どの工程のカットを一覧に並べるかを選びます。一覧表示とフローチャート表示を切り替えられます。
3. **カットの一覧**（右）：選んだ工程にいるカットが並びます。ここから、ファイルを開いたり、アクションを実行したりします。

左右の境目をドラッグすると、左側の幅を変えられます。
左側の幅に合わせて、上部のボタンの並び方（1行〜4行）が変わります。
左側の幅や表示の状態は、次に起動したときにも引き継がれます。

## 上部のボタン

| ボタン | 働き |
|---|---|
| **一覧表示／フローチャート表示の切り替え**（矢印のアイコン） | 工程の選択を、一覧表示とフローチャート表示とで切り替えます。 |
| **プロジェクトID** | 使うプロジェクトを選びます。Stuff フォルダの `projects` フォルダにあるプロジェクトが並びます。 |
| **設定**（Windows の歯車ボタン） | メニューから **プロジェクト設定**、**環境設定**、**PPM について** を開きます。 |
| **話数** | 作業する話数を選びます。話数を使うプロジェクトでだけ表示されます。 |
| **リスト更新** | カットの一覧を作り直します（[カットがリストに並ぶ条件](scene-list.ja.md) を参照）。 |
| **カット登録** | カットを工程グループに登録したり、カット情報を付け外ししたりします（[カットの登録](registering-scenes.ja.md) を参照）。 |
| **リテイク** | カットにリテイクを出します（[リテイク](retakes.ja.md) を参照）。 |
| **カット番号を入力**／**カットを検索**（虫眼鏡のアイコン） | カットの今の状態を調べます（下の「カット検索」を参照）。 |

macOS では **PPM** メニューから「PPM について」と環境設定を開けます。**プロジェクト → プロジェクト設定** で項目を選ぶと、そのページが直接開きます。ダイアログの左側でもページを切り替えられます。

### 話数の切り替え

話数を使うプロジェクトでは、**話数** で作業する話数を選びます。
話数が2つ以上あるときは、**全ての話数** を選ぶと、すべての話数のカットをまとめて一覧に並べられます。
このとき、一覧に **話数** の列が表示されます。

選んだ話数は、プロジェクトごとに記録され、次に起動したときにも引き継がれます。

## 工程の選択

左側では、一覧に並べたい工程のチェックボックスをオンにします。
オンにした工程にいるカットが、右側の一覧にまとめて並びます。
チェックの状態は、プロジェクトごとに記録されます。

工程を右クリックすると、**この工程から始めるカットを登録する** を選べます（[カットの登録](registering-scenes.ja.md) を参照）。
工程にマウスを重ねると、その工程の条件パス（**ファイル条件**）が表示されます。

### 一覧表示

工程グループごとに、工程が縦に並びます。

<!-- 画像：images/ja/using/list-view.png（一覧表示の左側。工程グループの見出しと、色付きの工程のチェックボックス、鍵のアイコンが見えている状態） -->

工程グループの見出しには、次のものがあります。

- **三角のアイコン**：工程グループを開いたり、閉じたりします。
- **工程グループ名のチェックボックス**：その工程グループの工程を、まとめてオン／オフします。名前の横の数字は、その工程グループに所属しているカットの数です。
- **更新ボタン**（回転矢印のアイコン）：その工程グループのファイルを探し直して、工程ごとのカットの一覧を作り直します（[カットがリストに並ぶ条件](scene-list.ja.md) を参照）。マウスを重ねると、説明が表示されます。

各工程の右端にある**鍵のアイコン**で、その工程のアクションを**ロック**できます（[カットに対する操作](scene-operations.ja.md) を参照）。

### フローチャート表示

プロジェクト設定で作った工程のつながりが、フローチャートで表示されます。
チュートリアルでは、こちらの表示を使っています。

![フローチャート表示](../images/ja/getting-started/tutorial-open-project.png)

- **工程グループの枠**：左上のチェックボックスで、枠の中の工程をまとめてオン／オフします。右上には、その工程グループに所属しているカットの数（「〇カット」）と、更新ボタン（回転矢印のアイコン）があります。
- **工程の四角**：チェックボックスで、その工程を一覧に並べるかどうかを選びます。白い数字は、その工程にいるカットの数です。数字にマウスを重ねると、カット名の一覧が表示されます。いちばん右の鍵のアイコンで、工程をロックできます（一覧表示と同じです）。
- **矢印**：アクションを実行したときに、カットが次に進む工程を表します。

マウスホイールで拡大・縮小、マウスの中ボタンを押したままドラッグで表示を動かせます。

#### 役割ボタン

フローチャートの右下に並んでいる色の丸は、**役割ボタン**です。
「演出」「監督」のように、プロジェクト設定で決めた役割ごとに、1つの色が割り当てられています。

役割ボタンを押すと、その役割と同じ色の工程を、まとめてオン／オフできます。
たとえば、演出の役割ボタンを押すと、LO・原画などの演出チェックの工程がすべてオンになります。
ボタンの上の印は、その色の工程のチェックの状態を表します（✓：すべてオン、－：一部がオン、印なし：すべてオフ）。

![役割ボタン](../images/ja/using/role-buttons.png)

## カットの一覧

右側には、選んだ工程にいるカットが1行ずつ並びます。

![カットの一覧](../images/ja/using/scene-list-table.png)

| 列 | 内容 |
|---|---|
| （チェックボックス） | まとめて実行するカットを選びます。アクションが1つだけの工程の行に表示されます（[カットに対する操作](scene-operations.ja.md) を参照）。 |
| **開く** | ファイルを開くボタンと、タイムシート・カットフォルダ・ログのボタンです。 |
| **工程** | カットがいる工程です。 |
| **形式** | プロトコルの形式（デジタル／紙／その他）です。 |
| **サムネイル** | カットのサムネイル画像です。プロジェクト設定でサムネイルの場所が決められている場合にだけ表示されます。 |
| **話数** | 話数を使うプロジェクトでだけ表示されます。 |
| **カット** | カット名です。テイク番号や工程内リテイクの印（`_t02`、`_r` など）も付けて表示されます。 |
| **最終更新日時** | キューファイルが最後に更新された日時です。今日なら時刻、今年なら月日、それより前なら年月日を表示します。 |
| **アクション** | 工程を進めるボタンです。工程内リテイクのボタンもここにあります。 |
| **情報** | カットに付いているカット情報のラベルです（[カット情報](scene-info.ja.md) を参照）。 |

一覧は、工程、話数、形式、カット名の順に並びます。
列の見出しをクリックすると、その列で並べ替えられます。

### 列の表示と、サムネイルの大きさ

列の見出しを右クリックすると、列の表示・非表示を切り替えられます。
**形式**、**サムネイル**、**話数**、**最終更新日時**、**情報** の列は、非表示にできます。
**開く**、**工程**、**カット**、**アクション** の列は、常に表示されます。

サムネイルを使うプロジェクトでは、同じメニューの **サムネイルの大きさ** で、**小** と **大** を切り替えられます。

## カット検索

上部の **カット番号を入力** の欄にカット名を入れて、Enter キーか虫眼鏡のボタンを押すと、そのカットの今の状態が右側に表示されます。

![カット検索の結果](../images/ja/using/scene-search.png)

| 項目 | 内容 |
|---|---|
| **工程グループ** | カットが所属している工程グループ（主流）です。 |
| **傍流工程グループ** | カットが傍流として追加されている工程グループです。 |
| **工程** | カットがいる工程です。複数の工程に同時にいる場合は、すべて表示されます。 |
| **テイク** | 今のテイク番号です。リテイクを出したカットでは、リテイク先、日時、コメントも表示されます。 |
| **カット情報** | カットに付いているカット情報です。 |
| **履歴** | カットのログです。 |

フローチャート表示のときは、カットがいる工程の四角が白い枠で強調され、その工程が見える位置まで表示が動きます。
右上の **✕** ボタンを押すと、カットの一覧に戻ります。

工程グループに所属しておらず、ログもないカットは、「検索されたカットは見つかりませんでした。」と表示されます。

## 終了するとき

Google スプレッドシートへの書き込みや Google Chat への通知が終わっていないうちに PPM を閉じようとすると、警告が表示されます。
**待つ** を押すと、PPM は閉じずに、送信を続けます。
**終了する** を押すと、送信されていない内容は書き込まれず、通知もされません。
