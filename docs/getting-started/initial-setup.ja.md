# 初回設定

PPM をはじめて起動したら、**環境設定**で、使う言語と作業用のアプリを設定します。
環境設定は PC のユーザーごとに保存されるので、各スタッフが自分の PC で一度行えば済みます。

Windows では歯車ボタンから **環境設定** を選びます。macOS ではメニューバーの **PPM** から環境設定を開くか、**Command+,** を押します。

![環境設定ダイアログ](../images/ja/getting-started/preferences.png)

> 導入担当者の方へ：Stuff フォルダに `defaultusersettings.ini` を置くと、全員の環境設定の初期値をまとめて決められます。
> 詳しくは [Stuff フォルダ](../administration/stuff-folder.ja.md) を参照してください。

## 言語を選ぶ

**言語** で、PPM の画面に表示する言語を選びます。
はじめは、OS の表示言語に合わせた言語になっています（その言語の翻訳ファイルが無いときは英語）。
変更は、PPM を次に起動したときに反映されます。

選べる言語は、Stuff フォルダの `loc` フォルダにある翻訳ファイルの言語です。
「English」を選ぶと、翻訳を使わずに英語で表示します。

## 各アプリのパスを設定する

PPM の一覧では、各カットのファイルを **開く** ボタンで直接開けます。
ファイルの種類ごとに、欄の右にある **...** ボタンでアプリを選びます。Windows では実行ファイル（`.exe`）、macOS ではアプリケーション（`.app`）を指定します。

| 設定項目 | 開くファイル |
|---|---|
| TVPaint実行ファイルのパス | TVPaint のプロジェクト（`.tvpp`） |
| Clip Studio実行ファイルのパス | CLIP STUDIO PAINT のファイル（`.clip`） |
| OpenToonz実行ファイルのパス | OpenToonz のシーンファイル（`.tnz`） |
| XDTS用アプリケーションのパス<br>（XDTS Viewer や東映アニメーションデジタルタイムシートなど） | タイムシートファイル（`.xdts`） |

パスを**空欄のまま**にした項目は、その拡張子に OS で関連付けられているアプリで開きます。
たとえば、`.clip` を普段から CLIP STUDIO PAINT で開いているなら、Clip Studio のパスは空欄のままでも構いません。

**OpenToonz起動時の引数** には、OpenToonz で `.tnz` を開くときに付け加える起動オプションを書けます。
OpenToonz のパスが空欄の場合は使われません。

設定したパスにファイルが見つからない場合は、PPM の起動時に警告が表示されます。
アプリのバージョンアップなどでインストール先が変わったときは、設定し直してください。

## ユーザー名

**ユーザー名 [USER_NAME]** は、プロジェクトの設定の中で `[USER_NAME]` と書かれた部分に入る名前です。
たとえば、個人ごとの作業フォルダのパスに `[USER_NAME]` が使われている場合や、カット表に作業者の名前を記録したいときに関係します。

空欄のままにすると、ログインしているユーザー名（欄に薄く表示されている名前）を使います。
別の名前を使いたいときだけ入力してください。
どんな名前を入れるべきかは、プロジェクトの設計者の指示に従ってください。

> カットの操作ログには、常にログインしているユーザー名が記録されます。
